# UPC 高分论文思路 / 扣分点 / 时间分配 — 中文圈素材摘录

整理日期：2026-10-23

标注 `〔推论〕` 的条目是我根据规则/访谈做的推断，不是原文表述，引用时请自行加限定。

## 0. 硬规则：先划出"红线"，红线内才有技巧

以下为竞赛官方规则（Rules）的**逐条英文原文摘录**，由一位 2022 年参赛并获银奖的同学从官网抄录精简：

- 论文必须用英文撰写，是正式论文（formal paper）；**每一页页首都要写队伍编号**。
- **论文中不得出现学生姓名、学校名称或任何可识别身份的信息**——即盲审。
- **首页只能有四项内容**：(1) 队伍编号；(2) 所选题目（"A" 或 "B"）；(3) 论文标题；(4) 一段不超过 **300 词** 的 summary，须是给出关键细节的摘要，包含对所提问题的回答、最终数值、结果与结论。
- 正文（首页之后）**长度不限**（"may be of any length necessary"）。
- 每篇论文**必须包含参考文献列表，并在正文中做文内引用**。
- 允许使用现有算法与计算工具（包括 Matlab / Mathematica 内的工具），**但必须正确引用、并在论文中清楚解释方法**。
- 论文可含公式、图、表。**自写程序可放附录，但所有算法、方法、结果必须在正文中解释，否则评审时不予考虑**（"to receive consideration during judging"）。
- 每篇论文**至少必须包含**：(1) 对本队所理解的问题的重述与澄清；(2) 对所做出的**全部假设与近似**的说明；(3) 对所有所做工作的**论证（justification）**；(4) 对所采用方法的**优缺点讨论**。
- 比赛期间可用书、期刊、计算机、互联网、自写程序等一切**非生命**资源，但**不得与队外任何人讨论**；指导教师不得有任何贡献。
- 允许做实验并在论文中呈现数据（题目本意是理论分析）。
- 提交：PDF/DOC/DOCX，邮件发至 `solutions@uphysicsc.com`，**必须在 48 小时结束前送达**。文件名 = 队伍编号 + 题号，例如 `778A.pdf`、`832B.doc`；邮件主题与正文都要写队伍编号；论文须作为附件，**不接受云盘链接**。
- 逾期后果：**逾期即不进入奖牌排名**；"稍微晚一点"的已注册队伍，评委*可以*把它评为 accomplished competitor（参赛成功），但**要拿奖牌必须在 48 小时内送达**。
[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]

> 这四件"至少必须包含"的事，基本就是评审的检查表。很多队伍栽在只写了 (1)(3)、没写 (2)(4)——尤其是"优缺点讨论"这一条，中文队伍最容易整段省略。〔推论〕

## 1. 摘要 / 首页：300 词是硬约束，也是最容易丢分的地方

- 官方对 summary 的要求不是"概述"，而是要**给出答案**：key details of the work performed, **answers to the questions posed, final numbers, results and conclusions**。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]
- 首页**只能**放四项（队伍编号 / 题号 / 标题 / summary）。换言之不能有目录、不能有作者、不能有学校 logo、不能有致谢。〔推论，依据同上〕
- 中文圈流传的模板把首页写成 `Title / Team / Abstract / Keywords`，第二页起 `Contents` → `Introduction` → `Model and formulas` → `Results and discussion`。[来源: 搜索结果 so-q10.md（max.book118《国际物理竞赛论文撰写-模板》）]
- 建议：摘要里必须出现**至少 3 个具体数字**（你算出的关键量 + 误差范围 + 一个对照量），否则等于没回答题目。〔推论〕

---

## 2. 论文骨架：把"四件事"落成章节

把官方四项要求直接映射成小节，是最省事、最不容易漏的写法：〔推论，映射依据 Cnblogs 规则原文〕

| 官方要求 | 建议章节 |
|---|---|
| (1) 重述与澄清问题 | 1. Problem restatement（明确你**选择**解释成什么物理场景，写清边界） |
| (2) 全部假设与近似 | 2. Assumptions（逐条编号 A1…An，每条给"为什么可以这样假设"的数值理由） |
| (3) 对所有工作的论证 | 3. Model / 4. Solution / 5. Results（每步给依据：文献、量级估计、或极限情形校验） |
| (4) 方法优缺点 | 6. Discussion：strengths & weaknesses（含失效边界、参数敏感性） |
| 参考文献 + 文内引用 | References（正文用 [1][2] 标注，不许只列不引） |
| 代码可复现 | Appendix（但方法必须已在正文讲过） |

## 3. 建模取舍：中文访谈里最集中的一条经验

- **"最大的挑战是确立物理模型"**——题目一旦和生活场景挂钩，要考虑的因素极多，**最终选择忽略哪些、着重哪几个，是最困难也最重要的**。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（余彦泽）]
- **归并同类项而不是穷举力**：为了高效建模，该队"放弃了分析蹦床中可能存在的所有力"，把**阻力与驱动力都归并为和形变成正比的简单方程**，并假设单人蹦跳过程中**高度守恒**来反解参数，从而大幅简化建模。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（李明睿）]
- **假设必须被"合理解释"**：需要决定哪些因素关键、哪些可忽略，并**合理地解释这些决策**；手段是"细致的列式演算、图形展示、深入的文献研究和团队的积极讨论"。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（隽昕哲）]
- **先估工作量，再决定方向**：对每一种设想"没有去埋头推算，而是**大致列式预测工作量**，选择相对重要且易于计算操作的方面为目标"——这是 48 小时内最实际的取舍准则。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（余彦泽）]
- **查文献 + 参考真实产品参数**来支撑模型选择（"多查阅一些文献，参考市面上相关产品的特点"）。[来源: 同上]
- **先做"排除法"再定方向**：太空跳水题里"影响因素非常的多：速度、加速度、热量、人体承受能力等等"，队伍"排除了许多看似是制约因素，但其实**影响有限、对最大高度影响不大**的制约条件"，最终只从**动力学 + 热力学**两条线算最大高度。[来源: SJTU-2024-UPC获奖者说-多元学习激发创造与探索.md（江楠）]
- **假设的合理性 = 数值差异问题**："部分物理量对于不同受力物体来说数值差异巨大，并受诸多因素影响，因此需要在短时间内确定合理的假设，在尽可能贴近现实情况的条件下简化模型"。[来源: SJTU-2024-UPC获奖者说-面对困境勇敢迈出第一步.md（郭润双）]
- **允许"自己的想法"，但必须在读过文献之后仍然站得住**：开放性题网上没有标准解，"可以代入自己的一些点子，但是**想法一定要在阅读论文之后仍然合理**"；建立模型前先读资料、对会发生的物理过程有大概了解。[来源: SJTU-2024-UPC获奖者说-多元学习激发创造与探索.md（顾家瑞）]
- **别去啃完全陌生的背景知识**："不要眼高手低，花太多精力研究你们从未涉及的背景知识，**用之前学过的内容，争取先把论文完成**"。[来源: SJTU-2024-UPC获奖者说-面对困境勇敢迈出第一步.md（陈睿扬）]
- **不要追求完美**："现实情景里永远有理论模型没有考虑到的因素，我们需要的是**抓住主要变量**"。[来源: SJTU-2024-UPC获奖者说-面对困境勇敢迈出第一步.md（郭润双）]
- **中途推翻模型是常态，要敢取舍**：金牌队 A422 成员原话——"最开始很确信的模型在中途出现**致命错误**，剩余时间紧迫，这不仅需要我们**冷静取舍**，更需要团队成员的相互支持与体谅"。[来源: SJTU-2025-密院学子UPC金牌加3.md]
- **把"能在没有计算机的年代用"作为建模目标**（2025 B 题）：南航 B207 队编制出火炮射表，"能让指挥员在没有计算机的年代仅凭查表和简单修正，就将目标打击误差控制在米级"——**结果可用性**本身就是加分点。[来源: WeChat-2025-金奖加5.md]
- **在关键物理区间上做真改进**：B207 队"创新性地引入了 **Loth 阻力系数模型**，成功解决了传统公式在**超音速与亚音速过渡区**的失效问题"——一个具体的、可命名的模型改进，比堆十个平庸修正更能打动评委。[来源: WeChat-2025-金奖加5.md]
- **建立误差/不确定性框架**：南航 5 支金奖队均选 B 题，"通过建立完善的**弹道动力学与误差分析框架**，为设计参数的高精度反演与评估提供了关键理论支持"。[来源: WeChat-2025-金奖加5.md]
- **做两套模型互相印证**：上科大金奖队"通过将**理论分析与数值模拟**结合，不断完善和优化研究方案"，并画出了"两种空间站排空模型分析图"。[来源: ShanghaiTech-2025-首次摘金上科大本科生UPC金奖-官网.md]

## 4. 图表 / 量纲 / 误差

- 金奖队图注是被单独展示的，说明**图是评审的第一眼**。已见金奖图类型（可直接对照自查）：
  - 受力分析图 / 自由体图（蹦床、降落伞、炮弹）
  - 关键量随时间变化曲线（空间站压力 vs 时间；温度 vs 高度与时间）
  - 二维参数平面 + 投影（延迟下落时间差 vs 最高弹起高度的关系及其二维投影）
  - 误差曲面 + 箱线图（射表误差随射击高程差与射程变化的曲面图及箱线图）
  - 参数分布图（击中目标的参数分布）
  - 关系曲线（风速 vs 偏移角度；不同水平风速下初速度 vs 发射角）
  [来源: SJTU-2024-密院学子在2023年UPC再创佳绩.md；SJTU-2025-密院学子UPC金牌加3.md；WeChat-2025-金奖加5.md；SJTU-2026-学院学子在2025年UPC再创佳绩.md]
- 图里最好有**量纲正确的坐标轴 + 单位 + 参数取值**，并且图注能独立读懂。〔推论〕
- 误差不要只报一个百分数：金奖级做法是给出**误差随参数变化的曲面貌线**或**分布/箱线图**，说明误差在哪个区域爆炸。[来源: WeChat-2025-金奖加5.md（B207、B155 图）]
- 概念图/示意图可用 dimo.design 或 CAD 画，队友用 CAD 效果也不错。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]

## 5. 参考文献与可复现

- 官方强制：**必须有参考文献列表 + 文内引用**；用现成算法/工具也必须引用并解释方法；**代码进附录不算"解释过"，方法必须在正文**。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]
- 文献检索的实操链路（中文圈常用）：x-mol 搜文章（关键词/整题）→ 谷粉学术查 DOI → 百度学术导出参考文献格式。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]
- 可复现性：把"参数—代码—图"三者对齐（同一组参数能重跑出同一张图），并在正文写出求解器/库版本。〔推论〕
- 一个正面样本：2025 A 题金奖队把整套 MATLAB IIR/SOS 滤波器实现开源，含明确的性能指标（延迟 < 0.5 ms、THD < 0.5%、实时倍数 > 100×、内存 < 1 MB、通带平坦度 < 0.1 dB），这类"指标表"正是论文里最容易得分的部分。[来源: CSDN-2026-UPC金奖开源项目-萨桑多声学.md]

## 6. 扣分点 / 风险清单（按"致命 → 轻微"排）

**致命（直接出局或掉档）**
1. **超时提交**——48 小时内没到邮箱就不进奖牌排名，最多被评委"酌情"记为 accomplished competitor。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]
2. **首页/正文出现姓名、学校、任何身份信息**——违反盲审要求。[来源: 同上]
3. **首页塞了四项以外的东西**（目录、致谢、队名、校徽）。[来源: 同上]
4. **文件名/邮件主题没写队伍编号**（应为 `778A.pdf` 这种）。[来源: 同上]
5. **交云盘链接而不是附件**。[来源: 同上]
6. **全文没有参考文献或没有文内引用**。[来源: 同上]
7. **方法只写在附录代码里，正文没解释**——规则明确"评审时不予考虑"。[来源: 同上]

**重扣（明显拉低档次）**
8. **没有"假设与近似"章节**，或假设只列不证——官方四项最低要求之一。[来源: 同上]
   - 这条在**指导教师**层面有直接证据：金牌队成员说"我们这次比赛**着重注意说明了物理模型的前提假设（Assumptions）**，这也是**屈子杰老师在给我们做讲座时着重提到的**。**最后的结果其实是其次的**，但是要把模型成立的因素都考虑进来"。[来源: SJTU-2024-UPC获奖者说-面对困境勇敢迈出第一步.md（伍浚涛）]
   - 即：交大的官方指导口径是"**假设 ≥ 结果**"，而多数队伍把篇幅几乎全给了推导与结果。〔推论〕
9. **没有"方法优缺点/失效边界"讨论**——中文队伍最常整段省略的一项。[来源: 同上]〔该"最常省略"为推论〕
10. **堆公式但不算数**：只推导不给最终数值/结论。官方要求摘要给出 final numbers、answers to the questions posed。[来源: 同上]
11. **模型不可复现**：参数不写、初值不写、求解器不写，图无法重跑。〔推论〕
12. **把"所有因素"都建模**导致 48 小时内做不完——SJTU 金牌队的做法恰恰相反（归并阻力与驱动力、用高度守恒假设降维）。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md]
13. **中途发现模型错了却不敢改**，硬着头皮写完——A422 的经验是必须冷静取舍。[来源: SJTU-2025-密院学子UPC金牌加3.md]

**注意（合规边界）**
14. **AI 工具可以用，但要谨慎**：2024/2025 两届获奖者都公开提到用 AI 减负（"借助 AI 工具减轻工作量"；"AI 工具帮我们节省了至少 30% 的重复性工作耗时"）。规则只禁止与**队外的人**讨论、禁止指导教师贡献，未禁止软件工具；但论文不得出现身份信息、且方法须自己解释清楚。[来源: SJTU-2025-密院学子UPC金牌加3.md；WeChat-2025-金奖加5.md；规则见 Cnblogs-2022-UPC赛前准备-银奖选手.md]
    → 稳妥做法：AI 用于**代码脚手架、绘图美化、语言润色**，物理建模与结论自己把关，并在方法处说明所用工具。〔推论〕
15. **英文写作是硬门槛**：SJTU 获奖者把"英语写作、MATLAB 绘图、LaTeX"列为**必须平时积累**的三项，"比赛期间当场学会很仓促，很可能来不及"。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md]

## 7. 48 小时时间分配

**一份可直接照抄的金奖时间表**（2025 A 题金奖，重庆邮电大学）：

| 时段 | 任务 | 时长 |
|---|---|---|
| 00:00–08:00 | 查资料、定方案 | 8 h |
| 08:00–24:00 | 写代码、调试 | 16 h |
| 24:00–32:00 | 优化、测试 | 8 h |
| 32:00–48:00 | 写论文、整理 | 16 h |
[来源: CSDN-2026-UPC金奖开源项目-萨桑多声学.md]

同一份材料里的另一版切分：步骤 A–E（需求分析→声学建模→模拟滤波器→数字化→SOS 分解）16 h（第 1 天）；F–H（MATLAB 实现→性能测试→达标判定/迭代）16 h（第 2 天）；论文撰写 16 h（第 2–3 天）。[来源: 同上]

其它时间相关经验：
- **开局就定时线，含"选题死线"**：金牌队 A131"一开始就制定了分工合作，分成物理建模、编程和文稿编辑三项"，并"在一开始就明确了任务完成的时间线……比如我们在拿到题目后就给自己定下**中午 12:00 前确定选题**的目标"。[来源: SJTU-2024-UPC获奖者说-面对困境勇敢迈出第一步.md（伍浚涛）]
- **论文可以边建模边写**："论文不必等到建模和作图全部完成后才开始写，只要**大致的模型建好了就可以先把假设、物理常数等写上去**，这样可以避免最后一天熬夜"。[来源: SJTU-2024-UPC获奖者说-多元学习激发创造与探索.md（顾家瑞）]
- **每阶段留"流动时间"，前期抓紧**："每个阶段留出一些流动时间……在前期稍微抓紧一些时间，这样就算后期遇到问题也能有足够的时间解决"。[来源: SJTU-2024-UPC获奖者说-多元学习激发创造与探索.md（许子钰）]
- **写作要并行、不能等模型定稿**："负责文献写作的同学要**紧跟模型建立的进度，并尽早开始撰写**，以避免在比赛的最后阶段因时间紧迫而压力过大"。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（隽昕哲）]
- **最后 6 小时仍在改**：金牌队 A131 成员"在提交的最后 6 个小时，我们仍在坚持不断地调整优化可改进的地方"——预留缓冲是常态。[来源: SJTU-2024-密院学子在2023年UPC再创佳绩.md]
- **按预设计划推进**："两天内完成了赛题分析、模型建立、求解绘图、论文写作等任务……**按预设计划推进进度**"是 B204 队自认的夺金关键。[来源: WeChat-2025-金奖加5.md]
- **作息**：赛前几天别熬太狠保存体能；48 小时内注意休息、合理安排精力。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]
- **心态三句**："提交就是胜利""语文建模也是建模""参赛过程也是学习过程"。[来源: 同上]

## 8. 三人分工

- 一个已验证的分工模板（SJTU 金牌队）：
  - 1 人：**建模 + 编程 + 制图**
  - 2 人：**前期模型确定 + 论文撰写**
  [来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（团队介绍）]
- 关键不是"三个人都会建模"，而是**写作的人从第一天就在场**（否则最后 16 小时必崩）。[来源: 同上；时间表见 CSDN-2026-UPC金奖开源项目-萨桑多声学.md]〔推论〕
- 另两种已验证的三分法（可与上表互补）：
  - A131：**物理建模 / 物理建模+编程 / 制图与调整**（"一项任务完成后，大家也会相互帮忙"）。[来源: SJTU-2024-UPC获奖者说-面对困境勇敢迈出第一步.md]
  - 江楠队：**研究方向确定+论文撰写 / 公式推导+模型构建 / MATLAB 代码+出图**。[来源: SJTU-2024-UPC获奖者说-多元学习激发创造与探索.md]
- **沟通机制本身是难点**："有些任务无法个人独立完成，有些任务又需要接替组员的任务完成"；解法是"整个过程都积极交流进度"，并用**线上协作平台**"在开始工作前划定大致框架，之后不断更新自己的内容和进度"。[来源: SJTU-2024-UPC获奖者说-多元学习激发创造与探索.md（许子钰）]
- 队长视角："**把握大方向，进行合理而高效的分工，积极地讨论与思维碰撞**是我们组成功获得金奖的关键"。[来源: WeChat-2025-金奖加5.md（B204 顾晨望）]
- 团队氛围被反复强调："比赛中最重要的是团队成员间的**相互理解和包容**，建立一个和谐的团队氛围对于成功至关重要"；A422 也强调"团队成员的相互支持与体谅"。[来源: SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md；SJTU-2025-密院学子UPC金牌加3.md]
- 异地也能打：上科大 2024 金奖队一人正在 UC Berkeley 交换、两人在校，"克服了空间距离和时差带来的困难"，靠线上协作完成。[来源: ShanghaiTech-2025-首次摘金上科大本科生UPC金奖-官网.md]

## 9. 选题策略：A 还是 B

- **没有"中国学生更适合哪题"的证据**，但有两个可观察的规律：
  1. **A 题（偏"设定好的物理系统"）选择人数远多于 B 题**：2023 年交大 37 支队选 A、15 支队选 B。[来源: SJTU-2024-密院学子在2023年UPC再创佳绩.md] → 选 A 意味着**同题竞争更激烈**。〔推论〕
  2. **B 题（偏"工程/参数反演"）是 2025 年的金牌富矿**：南航 5 支金奖队**全部**选 B（火炮射击参数评估），南理工 6 金也以工程参数类见长；B 题更像"建模 + 误差分析 + 做出可用产物（射表）"，与中国学生数模训练高度同构。[来源: WeChat-2025-金奖加5.md；NJUST-2026-第十六届UPC金奖数全国第一.md]
- **选题前先做"可交付性"判断**：能不能在 48 小时内产出一个**可被引用/可被查表使用**的结果？B207 的射表就是典型。[来源: WeChat-2025-金奖加5.md]
- 历年题目走向（用于预测 2026）：
  - 2023：A 火箭运载跳伞者再入大气层（最大安全落地高度）；B 三名不同体重/弹跳力儿童在蹦床上同跳（各自最大高度）。[来源: SJTU-2024-密院学子在2023年UPC再创佳绩.md]
  - 2024：A 空间站空气泄漏时间（可压缩性/空气动力学）；B 火星电力供应。[来源: SJTU-2025-密院学子UPC金牌加3.md]
  - 2025：A 印尼传统弦乐器萨桑多的电声化改造（声学保真 + 便携）；B 历史火炮弹道测算（初速与仰角反演 + 无电子设备辅助的射表）。[来源: SJTU-2026-学院学子在2025年UPC再创佳绩.md；NUAA-2026-我校学子在2025年UPC获5项金奖.md]
  - 规律：**一题"奇特场景 + 保真/优化"，一题"经典力学 + 参数反演/工程可用性"**。〔推论〕

### 中文圈评价（口碑面）
- "这个比赛**知名度没有美赛国赛高**，但对理工科大学生**极其友好**（指不需要什么准备成本），提前一天看看比赛要求和论文模板就 OK 了。比赛流程和数模也比较像。"[来源: Zhihu-345774623-UPC需要什么能力如何准备-FETCH-BLOCKED.md（知乎 pin 摘要）]
- 知识门槛："经验就是把知识水平控制在**高中物理竞赛、普物**这块就好了"。[来源: 同上]
- "**提交就是胜利**""**语文建模也是建模**"——即写作与表达的重要性不低于建模本身。[来源: Cnblogs-2022-UPC赛前准备-银奖选手.md]
- 定位差异：UPC 是**48 小时限时提交正式论文**的开放性物理建模赛（2–3 人），与 PUPC（普林斯顿物理竞赛，个人笔试型）、CUPT（中国大学生物理学术竞赛，答辩/辩论型）不是一类；它与 MCM/ICM 的流程最接近，但**物理味更重、准备成本更低**。〔推论，依据：赛事规则 + 知乎评价 + 各校战报描述〕
- 保研/留学用途：本次未取得中文圈关于 UPC 加分权重的直接证据（知乎相关问答与小红书内容均被风控）。可确认的间接信号是：各校把它作为**学校层面宣传的 International 赛事**（南航/南理工/上交/上科大均发官网战报），且获奖者常同时具备 MCM M 奖等背景。[来源: 各校战报；SJTU-2024-UPC获奖者说-化繁为简厚积薄发.md（团队介绍）]
  → 结论：**校内认定度取决于各校竞赛目录**，不能一概而论；UPC 不在教育部认可的"全国普通高校大学生竞赛目录"内（该目录为国内赛事白名单）。〔推论，需按目标院校推免细则核对〕
