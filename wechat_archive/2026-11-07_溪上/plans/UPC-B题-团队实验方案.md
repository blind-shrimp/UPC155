# UPC B题团队实验方案

**实验名称：基于真实轨迹校准与仿真训练的点球穿越位置概率预测**  
**日期：2026-11-07**  
**状态：待执行方案；除解析基线外，模型性能与实验结果均待验证。**

## 1. 目标与总体路线

仅使用球心在 **0.05 s、0.10 s** 的三维位置，预测球第一次向前穿越 **x=11 m** 时的位置，并给出不确定性区域。初始位置固定为 **(0,0,0.11) m**。

**真实数据整理 → 校准物理仿真 → 生成仿真数据 → 训练概率网络 → 独立测试 → 应用于题目案例。**

预测时不能输入真实初速度、旋转或最终穿越点；这些信息只能用于校准、生成训练数据或验证。

## 2. 真实数据准备

优先使用公开或赛前已取得的数据。比赛期间不安排队外人员定制采集、处理或分析；具体边界见[官方规则](https://www.uphysicsc.com/contestrules.html)。

| 数据项 | 要求 |
|---|---|
| 必需 | 每次踢球的时间戳、三维球心坐标、单位、离脚时刻 |
| 验证标签 | 球门穿越位置，或足够完整的后续轨迹 |
| 质量信息 | 采样频率、标定方式、测量误差 |
| 可选 | 初速度、旋转、球型、风速 |

处理步骤：统一坐标系和时间零点，检查缺帧、异常值与时间同步误差。无法可靠恢复三维位置的数据，不用于主要定量验证。若需插值到指定时刻，应记录插值误差，避免用后期轨迹拟合出的早期位置造成信息泄漏。

按**整次踢球**划分真实数据：

- **校准集约70%：** 估计物理参数及误差范围。
- **最终测试集约30%：** 封存，最后一次性评价。
- 数据很少时采用交叉验证；每折都必须重新校准仿真并训练模型，避免测试信息进入上游步骤。

## 3. 构建并校准物理仿真

依次建立：**重力 → 重力与二次阻力 → 重力、阻力与有效马格努斯升力**。

利用真实校准集的完整轨迹估计初速度及空气动力学参数，结合文献限制合理范围。先控制参数数量；风、旋转衰减等作为稳健性情景，不同时自由拟合。

检查：轨迹残差、端点误差、参数合理性，以及不同参数组合是否能解释同一观测。

程序验证：

1. 关闭空气动力项，应恢复抛体解析解。
2. 收紧积分容差，结果应稳定。
3. 使用事件检测定位球门穿越；球心下降至球半径时判为触地。
4. 触地、有效空中穿越、未穿越分别记录，不能继续积分地下轨迹并当作真实结果。

## 4. 生成仿真数据集

先生成 **1万条轨迹**跑通流程，再按学习曲线扩展至约 **10万条**。数量是初始建议，不是固定要求。

| 内容 | 生成方式 |
|---|---|
| 初速度、有效升力参数 | 从校准结果及文献支持的范围采样 |
| 阻力、球参数 | 在合理范围内变化，并保留参数相关性 |
| 观测误差 | 按真实测量质量加入；另设误差敏感性情景 |
| 网络输入 | x₀.₀₅、y₀.₀₅、z₀.₀₅、x₀.₁₀、y₀.₁₀、z₀.₁₀ |
| 主要标签 | 球门穿越坐标 Y、Z |
| 辅助记录 | 到达时间、物理参数、触地或未穿越标记 |

按完整轨迹划分 **80%训练、10%验证、10%测试**。同一轨迹的不同噪声版本必须放在同一集合。

触地或未穿越样本单独记录。主体端点模型适用于**有效空中穿越**；报告筛选条件和被排除比例，不能无说明地删除样本。如果需要预测任意射门，则另加事件类别预测模块。

## 5. 训练概率网络

采用小型**混合密度网络（MDN）**：

- 输入：六个早期位置坐标。
- 输出：球门平面上的二维混合高斯分布。
- 损失：真实端点的负对数似然。
- 用验证集选择网络规模及混合分量数，采用早停。
- 标准化参数仅从训练集计算；记录随机种子和训练配置。

输出**最可能穿越点、联合50%和95%预测区域**。最可能点使用分布众数的数值估计，不把均值直接称为最可能点。

如果测量精度已知且在样本间变化，应将精度作为额外条件，或分别训练。题目没有给定测量误差，因此案例需分别报告明确的误差情景，不能声称存在唯一的95%范围。

## 6. 对照与消融实验

| 方法 | 作用 |
|---|---|
| 恒加速度外推 | 简单基线 |
| 物理约束概率推断 | 比较网络与直接物理方法的准确性、校准和速度 |
| 普通回归网络 | 比较点预测表现；本身不提供概率区域 |
| 混合密度网络 | 主体方法 |

所有方法使用相同测试输入。增加两项消融：

1. 未经真实数据校准的仿真训练，对比校准后的效果。
2. 不加入观测噪声训练，对比加入噪声后的稳健性。

## 7. 独立评价

顺序：**留出仿真测试 → 改变空气动力学假设的测试 → 封存真实数据测试**。

| 主要指标 | 报告方式 |
|---|---|
| 端点误差 | 中位数、90%分位数，单位米 |
| 联合区域覆盖率 | 50%、95%区域包含真值的实际比例 |
| 区域面积 | 在相近覆盖率下比较，单位平方米 |
| 推断耗时 | 单次预测耗时，同时注明硬件条件 |

按速度、旋转强度和观测误差分组；真实数据缺少分组标签时，不作无依据的分组。覆盖率附样本量及统计误差。

若使用验证数据调整概率区域，应继续保留独立测试集。最终测试结果不再用于调参；覆盖率接近95%且区域足够集中，才说明概率预测有实际价值。

区分真实准确性与仿真一致性：只在同一仿真器上表现好，不能证明真实球路预测准确。

## 8. 题目案例

输入：

```text
r(0)    = (0, 0, 0.11) m
r(0.05) = (1.50, 0.45, 0.44) m
r(0.10) = (2.96, 0.86, 0.74) m
```

恒加速度解析基线：

```text
x(t) = 30.4t - 8t²
y(t) = 9.4t - 8t²
z(t) = 0.11 + 6.9t - 6t²
```

第一次穿越 x=11 时：**T≈0.405 s，(Y,Z)≈(2.495,1.921) m**。

最终生成一张结果卡：预测点、端点热图、联合50%和95%区域、误差假设、适用条件，并与基线比较。

**该案例没有真实终点，只能展示条件性预测，不能证明准确性。**

## 9. 本地环境与团队分工

使用独立 Anaconda/Miniconda 环境：**NumPy、SciPy、pandas、Matplotlib、PyTorch**。先用CPU跑通小规模流程；有可用GPU再扩大训练。保存环境依赖和版本。

| 主要负责人 | 工作 | 交付物 |
|---|---|---|
| 队员A | 数据、文献、物理校准 | 数据说明、参数与假设表 |
| 队员B | 仿真、网络训练 | 数据生成程序、模型、训练记录 |
| 队员C | 独立评价、图表、论文 | 对比表、验证图、文稿 |

三人共同审核物理假设；写作与计算同步。最后预留检查时间，确保正文、参数和图表来自同一版本。

## 10. 最终交付与止损

最终交付：

- 数据说明、参数表、可复现代码与环境配置。
- 模型对比表及两项消融结果。
- 端点误差图、覆盖率图、案例概率热图。
- 适用条件、失败案例和现实验证局限。

止损原则：

1. 数据检索设时限；没有合格真实数据时先完成仿真研究，明确尚未验证现实准确性。
2. 物理校准和基础验证未通过时，不扩大网络或增加复杂物理项。
3. 概率结果不可靠时，先检查误差模型、数据划分和训练稳定性。
4. 不能把期望性能、目标覆盖率写成已获得的实验结果。
