# 学生B代码审查清单

## 现在请优先审查

1. `physics.py`的`acceleration`：升力使用横向旋转、相对风速；是否符合队员A最终选定的经验公式？现在公式只是开发假设。
2. `LOW/HIGH`：是独立分量的开发先验，不是球速/仰角/转速的真实联合分布。必须由文献和实测修订。
3. `simulate`：初始接地但上升不应触发停止，第一次下降触地终止；门线与触地同一步按先后判断。检查坐标与球心定义。
4. `inference.py`：混合提议分布q与p/q校正；有限样本、局部提议可能遗漏模式，应检查ESS和跨种子差异。
5. `experiment.py`：只输入允许的早期坐标与假设已知的测量噪声；训练验证测试按完整轨迹分割。
6. 指标：均值预测误差不等于众数预测误差；HDR不是高斯协方差椭圆；门框内球心概率不是含碰撞的真实进球概率。

## 已解决的方案问题

- 不将普通贝叶斯MC称为理论天花板。
- 不以采样次数代替有效样本量。
- 不把两次观测的位置差分当成额外独立信息。
- 不在零旋转、轴向旋转时产生除零升力。
- 不把起点球心高度等于半径判为已触地失败。
- 不把门外概率截掉后计算95%区域。
- 不将开发用毫米误差情景称为设备认证精度。
