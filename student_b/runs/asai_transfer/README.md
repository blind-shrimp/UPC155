## 3. 判读（由上述数值机械生成）

- 外部 4 例：manual 相对 none 在 1/4 例更低，平均差 16.44 cm（负值=更低）。
- 外部 4 例：pooled 相对 none 在 1/4 例更低，平均差 13.41 cm（负值=更低）。
- 迁移方向是否一致须逐例看表；仅 4 例主案例 + 11 例补充片段，不能估计总体准确率，也不据此回调 Asai 参数。
- 估计器：none 先验下 |后验均值−MAP| 平均 66.92 cm；manual 先验下 |后验均值−MAP| 平均 52.07 cm；pooled 先验下 |后验均值−MAP| 平均 42.89 cm。
- 若均匀先验下均值与 MAP 差距大、而方向先验下两者接近，则旧表“MAP vs 后验均值”的估计量差异是差异来源之一；本轮 n=3，只作归因证据，不作概率优越性结论。
- 参数化提醒：本阶段固定早期速度/基，与上一批按 v0 生成的升力向量不同，数值不可与 10.63 cm 直接相减。

## 4. 边界与失败处理

- 全部尝试保留：未收敛分支、触地提前终止、未越过目标面的预测都写入 JSON，不静默丢弃；观测帧若落在球半径以下会被排除并计数。
- 评分与拟合分离：`fit_prefix` 只接受前段数组，留出帧由 `score_case` 在预测固定后打开；测试用扰动未来帧验证拟合与预测不变、分数改变。
- DFL 前段为 0/0.04/0.08 s，目标面来自 case_config；ISSIA 为 25 fps 连续片段，前向轴只由前三点确定并同变换整条轨迹（含参考）。
- 三球数据此前均已查看，属探索性归因，不是独立盲评；不与冻结 P1 的分布均值直接比较。
